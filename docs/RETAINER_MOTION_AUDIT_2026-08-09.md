# 심복 전투 모션 감사 — 2026-08-09

## 목적

심복 역할의 목표지점 본체가 이동·공격 때 같은 확대 모션만 사용하고, 주그디에드의 재구성과 돌격부대 충원이 정적인 상태 아이콘으로 보이던 문제를 개선한다. 전투 판정과 목표지점 조작 좌표는 유지하면서 아트와 기존 코드 드로잉만 움직인다.

## 공통 모션 계약

- `RetainerMotionProfile`은 심복에 연결된 Cursor 안정 ID, 이동 방향, 공격 펄스, 상태와 진행률만 입력받는 순수 계산이다.
- 변형은 목표지점 아트에만 적용한다. 공격·회수 범위, 목적지 표시, 쿨다운 링과 입력 좌표는 움직이지 않는다.
- 새 파티클·애니메이션 노드를 만들지 않는다.
- 스케일은 0.65~1.30, 오프셋은 10px 이하, 회전은 0.25rad 이하, 알파는 0.30~1.00을 유지한다.

| Cursor ID | 전투 심복 | 이동·공격 자세 |
|---|---|---|

| `silver` | 수석심복 계열 | 부유 이동과 방사 팽창 |

## 상태 전환

- 합동 공격 직후 주그디에드는 `reconstructing` 상태로 전환한다. 진행률 0에서는 낮고 흐린 붕괴 자세, 진행률 1에서는 정상 실루엣으로 복귀한다.
- 재구성 오버레이의 뼈 조각은 진행률에 따라 바깥 궤도에서 본체 중심으로 조립된다.
- 돌격부대 인원은 미세한 행진 위상을 사용하고 처형으로 인원이 소모되면 외향 펄스, 충원되면 수렴 펄스와 신규 인원 확대를 표시한다.
- 상태 표시는 기존 컴포넌트가 소유하며 공격 가능 여부·재구성 시간·충원 시간 규칙은 변경하지 않는다.
