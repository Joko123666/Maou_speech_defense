- 기준: S1~S3 완료 뒤 4,092행·395개 인스턴스 함수
- 성격: 정적 감사. 런타임 코드·수치·씬·리소스는 변경하지 않음

## 1. 결론

`GameController`의 가장 큰 함수는 38행이고, 395개 중 243개가 10행 이하입니다. 20행 이상 함수는 30개이지만 대부분은 이미 전용 서비스의 입력과 결과를 연결하는 장면 오케스트레이션입니다. 따라서 다음 개선은 파일 전체 분해가 아니라 직접 RNG·공간 질의·피해/상태 적용이 한 흐름에 남은 세 경계만 대상으로 합니다.

세 단일 구현 대상인 `SpiritAttackExecutionService`, `CursorHitEffectService`, `EnemySpecialActionExecutionService`를 모두 완료했습니다. 사령 공격, 치명 주 피해 전 보상 표식·생존 단계별 충돌/확산, 적 특수행동의 RNG·범위·증원 순서를 각각 독립 계약으로 고정했습니다. 최신 기준선 후속 재감사와 엄격한 품질 게이트, 전체 스모크 러너 재감사도 완료했습니다.

## 4. 상위 3개 잔여 경계

### 1순위 P1 — `SpiritAttackExecutionService` (완료)

추출 전 범위는 `_release_spirit_attacks()`, `_can_release_spirit_attacks()`, `_release_single_spirit_attack()`, `_apply_spirit_curse()`, `_resolve_spirit_blast()`, `_record_spirit_attack_summary()`의 6함수·61행이었습니다.

- 추출할 규칙: 요청 수 정규화, 매 사령마다 활성 적 재조회, 충전 한 기 예약, RNG 대상 선택, 저주를 피해 전에 적용, 반경 대상이 없을 때 주 대상 폴백, `spirit_summon` 실제 피해 합산, 사망으로 다음 표적이 사라지면 즉시 중단, 활성 소환의 마지막 위치·피해 갱신.
- 컨트롤러 유지: 실제 적·사령 컨트롤러 콜백, 저주 메트릭, 궤적·문양, 묶음 피해·적중 메트릭.
- 위험: 피해 콜백이 동기로 적 사망을 일으켜 다음 반복의 활성 적 목록을 바꿉니다. 충전 예약과 RNG 순서를 바꾸면 충전 손실 또는 RNG 지문 변화가 발생합니다.
- 필요한 계약: `활성 적 조회→충전 예약→RNG→저주→반경 조회→피해→활성 소환 갱신` 순서, 한 기씩 예약, 빈 반경 주 대상 폴백, 첫 사령 처치 뒤 다음 대상 재조회, 표적/충전 소진 중단, 실제 피해·적중·방출 수 구분, 안정 실패 사유.
- 선행 관계: 없음. S1~S3 서비스와 `NecromancyController`의 기존 예약 계약을 그대로 사용합니다.
- 구현 결과: `scripts/combat/spirit_attack_execution_service.gd` 155행·6함수로 규칙을 옮겼고 `GameController`는 4,077행·395함수의 실제 적·사령 콜백, 저주·묶음 메트릭과 궤적·문양만 연결합니다. 기존 `_can_release_spirit_attacks()`와 `_resolve_spirit_blast()` 참조는 0건입니다.
- 검증 결과: 독립 계약이 요청 3기 중 대상 소진 전 2기 방출, 매회 한 기 예약, 동기 사망 뒤 활성 적 재조회, 저주 선적용, 빈 반경 폴백, 실제 피해 190·3적중, 피해 뒤 연출·활성 소환 갱신과 의존성·충전 실패의 무부작용을 확인했습니다. Godot 파싱, 전체 스모크, 튜토리얼, verbose 오류·누수 검사는 모두 종료 코드 0입니다.

- 구현 결과: `scripts/combat/cursor_hit_effect_service.gd` 101행·6함수로 규칙을 옮겼고 `GameController`는 4,062행·394함수의 판결/일반 주 피해 콜백과 심복 상태 메트릭을 연결합니다. `_apply_cursor_on_hit_effects()`와 컨트롤러의 관련 modifier·`cursor_collision` 직접 참조는 0건입니다.

## 5. 제외한 항목

- `_run_signal_callbacks()` 38행은 가장 크지만 신호 콜백 사전을 구성할 뿐 게임 규칙을 계산하지 않아 유지합니다.
- Core·타워·투사체의 20행 이상 함수는 전용 서비스 결과를 실제 Node 피해·메트릭·연출로 연결하므로 다시 대형 서비스로 합치지 않습니다.
- 하단 타기팅·표현 함수는 테스트와 서비스에 전달되는 얇은 Callable 경계입니다. 직접 호출 제거만으로 결합도가 낮아지지 않으므로 유지합니다.
- 주다긴다 처형 공포, 목표지점 이동 궤적탄, 심복 재소환·희생 범위 효과는 게임 규칙이 남아 있지만 각각의 규모·독립성·현재 회귀 커버리지가 상위 3개보다 낮아 이번 백로그에 올리지 않습니다.
