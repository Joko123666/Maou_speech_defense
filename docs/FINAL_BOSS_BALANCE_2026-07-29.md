# 최종 보스 성장 곡선 재산정

## 기준

- 표준 스테이지는 10분이며 기존 목표 평균 레벨은 25다. 레벨 상한은 제거하지만 10분 도달 기대치는 밸런스 기준으로 계속 사용한다.
- 평균 Lv.25는 시작 레벨을 제외하면 24회의 선택 예산이다.
- 대표 완성 빌드는 편대 4회, 주력 타워 Lv.7까지 6회, 보조 타워 3회, 핵 3회, 목표지점 3회, 상태이상 2회, 전역 강화 3회로 계산한다.
- 일반 적이 계속 출현하는 최종전에서 주력 화력이 보스에게 온전히 집중되지 않는 점과 방어력 손실을 반영해 실효 보스 집중 DPS를 700~850, 중앙값을 750으로 둔다.
- 목표 처치시간은 45~55초다. 너무 짧으면 3단계 패턴이 보이지 않고, 너무 길면 열 비활성화와 일반 적 누적이 성장 선택보다 강하게 작용한다.

## 체력 계산

| 항목 | 이전 | 조정 |
|---|---:|---:|
| 데이터 기본 체력 | 13,000 | 9,000 |
| 10분 스테이지 체력 배율 | ×4.2 | ×4.2 |
| 실제 출현 체력 | 54,600 | 37,800 |
| 대표 DPS 750 기준 처치시간 | 72.8초 | 50.4초 |

목표 범위는 `700 × 45 = 31,500`에서 `850 × 55 = 46,750`이다. 조정 체력 37,800은 이 범위 중앙부에 위치한다.

## 방어·행동 조정

- 방어력: 16 → 12. 빠른 다단 공격이 방어력에 의해 최소 피해로 고정되는 비율을 줄인다.
- 상태이상 저항: 65% → 56%, 최종 단계 85% → 76%. 상태이상 빌드가 최종전에서 무효화되지 않게 한다.
- 넉백 저항: 93% → 87%. 완전 봉쇄는 어렵지만 제어 투자의 체감은 남긴다.
- 기본 이동속도: 34 → 31, 최종 단계 속도 배율: ×2.2 → ×1.75.
- 열 비활성화·소환 주기: 7초 → 9초. 50초 전투에서 약 7회가 아니라 약 5회의 패턴을 예상한다.

보스의 핵 돌파 피해는 최대 체력 비례 규칙을 유지한다. 따라서 처치 실패의 게임오버 위험은 보존하면서, 실패 원인이 과도한 체력·저항으로 고정되는 문제만 완화한다.
