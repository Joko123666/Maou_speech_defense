## 2. 구현 범위

### 전투와 조작

- 핵은 화면 왼쪽, 적은 오른쪽에서 등장하며 4개 행을 따라 전진합니다.
- 플레이어는 목표지점을 클릭·터치·드래그하여 행과 X좌표를 조절합니다.
- 타워는 자동 공격하며 역할에 따라 투사체 또는 즉시 판정 공격을 사용합니다.
- 핵 스킬은 시간 기반으로 충전되며 `Space` 또는 대응 UI로 사용할 수 있습니다.
- 보스는 2분 30초 간격으로 등장하고 10분에 최종 보스가 출현합니다.

### 편대와 성장

- 전장에는 6개 편대 열이 있고, 각 편대는 4개 행의 타워 조합으로 구성됩니다.
- 편대 설치 카드에서 타워·공란 조합을 미리 확인하고 설치 열을 직접 선택합니다.
- 같은 타워 종류의 레벨은 모든 편대에서 공유됩니다.
- 타워·핵·목표지점은 Lv.4에서 3개 전용 분기 중 하나를 선택하고 Lv.7에서 완성됩니다.
- 경험치 오브젝트는 적 처치 시 생성되고, 합체 및 목표지점 자석 회수를 지원합니다.

### 적과 보스

- 일반 적은 기본, 빠른, 무리, 중장갑, 분열, 지원, 이동, 상태 해제, 교란, 원거리의 10종입니다.
- 둔화, 빙결, 화상, 표식, 기절, 취약과 방어력·상태 저항·넉백 저항이 구현되어 있습니다.
- 보스는 격노, 교란, 소환, 최종 3단계 행동을 포함한 4종입니다.

## 6. 확인된 강점

- GDD의 주요 시스템이 데이터, 런타임 로직, UI, 자동 테스트까지 연결되어 있습니다.
- 핵심 콘텐츠가 `Resource` 계층과 레지스트리로 분리되어 확장이 비교적 쉽습니다.
- 투사체/히트스캔, 성장 분기, 편대 배치, 보스 타임라인처럼 오류 가능성이 높은 흐름이 스모크 테스트에 포함되어 있습니다.
- 1280×720 기준 UI 스냅샷이 있어 화면 회귀 비교의 출발점이 마련되어 있습니다.

## 8. 권장 다음 작업

1. 실제 10분 런을 5~10회 진행하고 `user://last_run_metrics.json`을 수집합니다.
2. 적 스폰 간격, 체력 배율, 경험치 곡선, Lv.4 파워 스파이크를 로그 기준으로 조정합니다.
3. 실제 모바일 기기에서 안전 영역, 드래그 정확도, 작은 텍스트, 일시정지 복귀를 검증합니다.
4. 후반 2분을 중심으로 CPU/GPU 프레임 타임과 활성 오브젝트 수를 측정합니다.
5. 전투 가독성 기준을 정한 뒤 타워·적·투사체·경고 연출의 최종 아트 방향을 확정합니다.
6. UI 스냅샷의 자동 이미지 비교를 추가하여 레이아웃 회귀를 탐지합니다.

## 9. 완료 기준 제안

다음 조건을 만족하면 프로토타입에서 알파 단계로 전환할 수 있습니다.

- 10분 런 10회 이상에서 크래시와 진행 불가 버그가 없습니다.
- 최소 2종 모바일 기기에서 평균 프레임과 발열 목표를 통과합니다.
- 핵·목표·편대 선택이 특정 조합 하나로 과도하게 쏠리지 않습니다.
- 보스 경고, 체력, 위험 행, 레벨업 선택이 전투 중 즉시 인지됩니다.
- 저장/해금/재시작 흐름이 앱 재실행 후에도 안정적으로 유지됩니다.
- 핵심 화면의 자동 UI 회귀 검사가 구축됩니다.
