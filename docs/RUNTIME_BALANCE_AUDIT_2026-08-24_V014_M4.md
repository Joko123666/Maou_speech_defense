## 고정 틱과 속도 등가성

기존 `Engine.time_scale`만 올리는 방식은 1×·2×·3×에서 렌더 프레임당 게임 시간 간격이 달라져 경험치 회수, 처치, 강화 선택과 편대 수가 달라졌다. 전투 판정을 담당하는 핵·목표지점·적·스폰·타워·투사체·소환·후보 컴포넌트·게임 조정기를 `_physics_process()`로 통일하고, 속도에 맞춰 물리 틱을 60/120/180Hz로 설정해 게임 시간 기준 1/60초 간격을 유지했다. 수집·병합 누적기는 임계값 초과분을 버리지 않고 잔여 시간을 보존한다.

감사 매트릭스에 `--speeds=1,2,3`과 시뮬레이션 지문 비교 게이트를 추가했다. `judgment_vanguard`, seed 1847, 60초 표본은 세 속도에서 모두 다음 값으로 일치했다.

| 지표 | 1× | 2× | 3× |
|---|---:|---:|---:|
| 경과 시간 | 60.0167 | 60.0167 | 60.0167 |
| 레벨 / 총 경험치 | 5 / 189.0 | 5 / 189.0 | 5 / 189.0 |
| 처치 | 54 | 54 | 54 |
| 기본 / 보너스 스폰 | 51 / 5 | 51 / 5 | 51 / 5 |
| 최종 일반+친위대 편대 | 3 | 3 | 3 |
| 코어 체력 / 커서 피해 | 170 / 277.1 | 170 / 277.1 | 170 / 277.1 |

자동 판정은 `speed_equivalence.checked=true`, `passed=true`, 불일치 0건이다.
