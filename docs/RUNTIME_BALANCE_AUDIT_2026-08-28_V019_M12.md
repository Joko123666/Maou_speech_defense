# GDD v0.19 M12 4정책×3시드 확대 감사

- 기준일: 2026-08-28
- 목적: M11의 단일 seed 정책 비교를 정책당 5후보×3시드×600초로 확대하고 STEP·특화·병력 효율 경고의 재현성을 판정
- 공통 조건: 5후보, seed 1847/42731/99881, 3배속, Bonus disabled, 아티팩트 normal
- 정책 조건: strong×average, average×average, weak×high, tangled×low

## 결론

4정책 60/60런이 최종 보스에 도전했고 품질·밸런스·성능 게이트를 통과했습니다. STEP은 strong 16.7%, average 13.3%, weak 72.7%, tangled 33.3%이며 모든 정책에서 배치 포기 0건, 평균 유효 위치 5.73~8.0칸입니다. 공통 배치 결함이 아니므로 편대 데이터와 선택 가중치는 유지합니다.

strong에서 지속 화력군 `area` 16.93 대 `rapid` 5.94의 효율 격차 2.85배가 남았지만 average는 18.42 대 16.25, tangled는 29.53 대 25.05로 재현되지 않았습니다. precision 계열 격차도 strong 15런에서는 기준 아래로 해소됐습니다. 따라서 병종 수치를 변경하지 않고 strong 정책·배치 문맥의 진단 신호로만 유지합니다.

여러 후보를 합친 전역 특화 경고는 후보 전용 진입·분기 선택을 섞는 오탐이었습니다. 혼합 시나리오 집계는 특화 편향을 정보성 `mixed_scenario_specialization_bias_deferred`로 이관하고, 실제 경고는 각 3시드 시나리오 진단에 보존하도록 개선했습니다.

## 감사 도구 개선

### 호환 체크포인트 부분 재사용

확장 구성의 체크포인트 서명이 달라도 각 보고서의 아래 조건이 모두 맞으면 재사용합니다.

- 감사 schema 19
- 빌드 정책 revision 3
- RNG revision 2
- 감사 시간, 시나리오, seed, 속도, 빌드/숙련 정책, Bonus/아티팩트 모드
- 블록 보드, 타임아웃, 성능 예산, 정책 행동 원장 품질 조건

실제 확대 실행에서 세 정책 모두 기존 seed 1847의 5개를 재사용하고 seed 42731·99881의 10개만 새로 실행했습니다. 최종 재요약은 각 체크포인트의 15개를 전부 재사용했습니다.

### 혼합 시나리오 특화 판정

- 단일 시나리오 또는 `by_scenario`의 3시드 셀은 기존 특화 미선택/과선택 판정을 유지합니다.
- 둘 이상의 후보 시나리오를 합친 최상위 집계는 특화 경고를 생성하지 않고 정보성 보류 사유를 남깁니다.
- 각 `policy_cells`는 전체 정책 진단과 별도로 5개 `scenario_diagnostics`를 보존합니다.
- 계약 테스트는 두 시나리오×3시드 합성 표본에서 전역 보류와 시나리오별 특화 경고가 동시에 유지되는지 검사합니다.

이 변경은 파생 요약과 체크포인트 재사용 규칙만 바꾸며 전투, RNG 소비, 선택 정책의 의미는 바꾸지 않습니다. 감사 schema 19·빌드 정책 revision 3·RNG revision 2를 유지합니다.
