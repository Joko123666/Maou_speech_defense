# TD Survival

[`godot_formation_defense_gdd_v0_19.md`](godot_formation_defense_gdd_v0_19.md)의 온보딩·메타 해금, 공통 성능 언어, 2분 주기 운반 정예 아티팩트 방향으로 이행하는 Godot 4.7 프로토타입입니다. 기본 실행 프로필은 후보·심복·선거·통치 흐름이 연결된 `demon_election_vertical_slice.tres`이며, 실제 구현과 대조한 단계별 작업·완료 조건은 [`docs/GDD_V0_19_IMPROVEMENT_PLAN.md`](docs/GDD_V0_19_IMPROVEMENT_PLAN.md)를 따릅니다. 기존 v0.16 전투·감사 기반은 유지하며, 무아티팩트 밸런스 기준선을 동결한 뒤 메타 진행 → POWER/SPEED/RANGE → 아티팩트 순으로 증분 적용합니다.

`reference/UIUX_001~003.png`의 전투 HUD·선택 카드·유닛 정보 팝오버를 기존 UI 상태와 대조한 전체 개편안은 [`docs/UI_UX_OVERHAUL_PLAN_2026-08-28.md`](docs/UI_UX_OVERHAUL_PLAN_2026-08-28.md)에 정리되어 있습니다. M0의 화면·전장 좌표 기준선부터 M7 반응형·접근성·성능 자동 승인까지 구현했습니다. 타이틀 성채와 유세 본부 배경을 분리하고, 전장 배경 2종과 하단 75px 동적 관중 밴드를 함께 사용합니다. 현재 Forward Mobile 자동 화면은 전용 타이틀 상태를 포함한 85개이며 Android 실기기 최종 승인만 남아 있습니다.

## 실행 환경

- Godot 4.7 stable
- Mobile 렌더러
- 1280×720 기준 가로 화면

Godot에서 `project.godot`을 열어 실행합니다.

## 사운드 리소스

효과음은 `assets/audio/` 아래의 `combat/`, `gameplay/`, `events/`, `ui/`에 WAV로 분리됩니다. 공용 UI·성장·보스·결과음 외에 핵 액티브 5종과 속사·폭발·에너지·톱날·비전 타워 공격군 5종이 각각 전용 음색을 사용합니다. 원본은 mono 44.1kHz/16-bit PCM으로 생성하고 Godot에서 QOA로 가져오며, 16보이스 풀과 45ms 반복 타격 슬롯으로 3배속 중첩을 제한합니다. 외부 라이브러리 없이 다음 명령으로 동일하게 재생성할 수 있습니다.

```powershell
python tools/generate_sfx.py
```

사운드 역할과 승인 규격은 [`docs/AUDIO_PRESENTATION_AUDIT_2026-08-04.md`](docs/AUDIO_PRESENTATION_AUDIT_2026-08-04.md)에 정리되어 있습니다.

## 검증

```powershell
godot --headless --editor --path . --quit
godot --headless --path . res://tests/smoke_test.tscn
```

구조 변경이나 통합 검증에는 PASS 문자열뿐 아니라 런타임 오류와 종료 누수까지 함께 판정하는 통합 게이트를 사용합니다. `full`은 파싱, 콘텐츠·선거 런타임, 메타 지속성, 전체 스모크, 튜토리얼, verbose 전체 스모크의 여섯 단계를 실행합니다.

```powershell
& .\tools\run_headless_quality_gate.ps1 -Mode full
```

판정기 자체만 빠르게 확인하려면 `-Mode selftest`, 분리된 콘텐츠·선거 단계는 `-Mode content`, 저장·체크포인트·메타 단계는 `-Mode meta`를 사용합니다. Godot을 자동으로 찾지 못하면 `-GodotPath`에 Godot 4.7 콘솔 실행 파일을 지정합니다. 단계별 원본 로그와 JSON 요약은 출력된 임시 보고서 경로에 보존됩니다.

현재 구현은 모든 기획 요소의 연결과 검증을 위한 러프 프로토타입입니다. 핵·타워·심복 전투 표식의 코드 기반 모션은 연결됐으며 수치 밸런스, 최종 SD 캐릭터 애니메이션·아트와 실제 기기 UX는 추가 반복 작업이 필요합니다.
